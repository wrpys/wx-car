# 二手车买卖小程序 · 二次设计规范

## 一、设计目标

在保留原稿「明黄主色 + 白底卡片 + 红色价签」品牌记忆点的基础上，做以下优化：

1. **降低视觉噪音**：弱化「急卖/评分」标签的冲突感，让车图与价格成为第一视觉焦点。
2. **统一信息层级**：首页、搜索、结果、详情使用同一套卡片与字体层级。
3. **提升精致度**：通过更克制的圆角、留白与微阴影，让界面更接近原生小程序品质。
4. **增强可用性**：搜索历史改为标签 chips、详情页信息按「关键参数 / 车辆档案」分组，降低阅读成本。

## 二、设计系统（Design Tokens）

### 2.1 色彩系统

| Token | 色值 | 用途 |
|-------|------|------|
| `--color-primary` | `#FFB800` | 主按钮、定位标、底部 Tab 激活态、急卖角标 |
| `--color-primary-light` | `#FFF5D6` | 浅色背景、选中态、标签底色 |
| `--color-price` | `#E53935` | 价格、强提示 |
| `--color-text-primary` | `#1A1A1A` | 主标题、车名 |
| `--color-text-secondary` | `#666666` | 副标题、里程、年份 |
| `--color-text-tertiary` | `#999999` | 辅助说明、占位符 |
| `--color-background` | `#F7F8FA` | 页面背景 |
| `--color-card` | `#FFFFFF` | 卡片背景 |
| `--color-border` | `#EEEEEE` | 分割线、边框 |
| `--color-success` | `#2E7D32` | 已检测、一手车等优势标签 |
| `--color-info` | `#1976D2` | 出险记录、检测报告链接 |

### 2.2 字体系统

| 级别 | 字号 | 字重 | 行高 | 用途 |
|------|------|------|------|------|
| H1 | 18px | 600 | 1.4 | 导航栏标题、车名 |
| H2 | 16px | 600 | 1.4 | 卡片标题、模块标题 |
| H3 | 14px | 500 | 1.5 | 筛选标签、小标题 |
| Body | 14px | 400 | 1.5 | 正文、参数值 |
| Caption | 12px | 400 | 1.4 | 辅助信息、时间、编号 |
| Price | 18px | 700 | 1.2 | 价格（红色） |

字体栈：`PingFang SC, -apple-system, BlinkMacSystemFont, Helvetica Neue, sans-serif`

### 2.3 间距系统

以 4px 为基准单位：

| Token | 值 | 用途 |
|-------|-----|------|
| `--space-xs` | 4px | 图标与文字间距 |
| `--space-sm` | 8px | 行内元素间距 |
| `--space-md` | 12px | 卡片内边距 |
| `--space-lg` | 16px | 卡片之间、模块间距 |
| `--space-xl` | 20px | 页面级间距 |
| `--space-xxl` | 24px | 大幅分隔 |

### 2.4 圆角与阴影

| Token | 值 | 用途 |
|-------|-----|------|
| `--radius-sm` | 6px | 小标签、输入框 |
| `--radius-md` | 10px | 卡片、按钮 |
| `--radius-lg` | 14px | 大图、弹窗 |
| `--radius-pill` | 999px | 胶囊标签、搜索历史 chip |
| `--shadow-card` | `0 2px 8px rgba(0,0,0,0.04)` | 卡片悬浮 |
| `--shadow-float` | `0 4px 16px rgba(0,0,0,0.08)` | 悬浮按钮 |

## 三、关键组件规范

### 3.1 车源卡片（Home / 搜索结果通用）

```
┌─────────────────────────────────────┐
│  ┌──────┐  丰田汉兰达2012款 2.7L...  │
│  │      │  2012年 / 15.63万公里 / 福州 │
│  │ 车图  │  [汽油] [代步车] [一手车]    │
│  │      │  市场价 3.85万              │
│  └──────┘                             │
└─────────────────────────────────────┘
```

- 图片：110×82px，圆角 8px，object-fit: cover
- 标题：14px / 600，单行截断
- 副信息：12px / #666，单行
- 标签：12px / #666，背景 #F5F5F5，圆角 4px，间距 6px
- 价格：16px / #E53935 / 700
- 卡片无描边，12px 圆角，白色背景，2px 微阴影
- 「急卖」改为左上角 4px 圆角小标签，背景 primary，文字白色，字号 11px

### 3.2 搜索输入框

- 高度 36px，圆角 18px（胶囊）
- 背景 #F5F5F5，聚焦时背景变白、边框 1px solid primary
- 左侧定位文字 14px / #1A1A1A + 下拉箭头
- Placeholder: #999

### 3.3 底部 Tab Bar

- 高度 56px + safe-area-inset-bottom
- 背景白色，顶部 0.5px 分割线
- 图标 24×24，未选中 #999，选中 primary
- 文字 11px

### 3.4 详情页图片画廊

- 顶部全宽，高度 280px
- 指示器：底部居中圆点，当前为 primary
- 「一键下载图片」改为右上角半透明白色胶囊按钮，图标 + 文字

### 3.5 关键参数网格

```
┌─────────┬─────────┬─────────┐
│ 2014-07 │ 10.85万  │  橙色   │
│ 上牌时间 │ 表显里程 │ 外观颜色 │
└─────────┴─────────┴─────────┘
```

- 三列等分，12px 字号，主值 14px / 600，标签 12px / #999
- 卡片背景 primary-light，圆角 10px

## 四、页面级 Redesign 要点

### 4.1 首页

- 顶部搜索区使用 **白底卡片** 包裹，而不是全黄背景，减少刺眼感；仅搜索按钮和定位下拉箭头使用 primary 黄色。
- 筛选栏：文字 14px，图标统一为 10px 倒三角，选中态文字 primary + 底部 2px 黄色指示线。
- 列表改为 **大卡片** 布局，每张车源独立成卡，增加呼吸感。
- 发布按钮改为右下角 56px 圆形悬浮按钮，primary 色 + 白色加号，带阴影。

### 4.2 搜索页

- 头部改为白底，仅保留返回箭头和搜索输入框；输入框获得焦点时底部出现 primary 色 2px 指示线。
- 「历史记录」改为横向可滑动的 **标签 chips**，单条记录不再占据整行，视觉更轻。
- 增加「热门搜索」模块，用不同颜色区分历史与推荐。
- 清空历史按钮放在标题右侧，图标化。

### 4.3 搜索结果页

- 与首页共用同一套车源卡片，保持体验一致。
- 顶部增加「共找到 N 辆车」+ 列表/网格切换（默认列表）。
- 空结果时提供「清除筛选」和「换关键词试试」引导。

### 4.4 车辆详情页

- 首屏：大图画廊 + 价格/编号 + 车名 + 标签 + 发布时间。
- 第二屏：关键参数网格（上牌时间 / 里程 / 颜色）。
- 第三屏：车辆档案两列参数表（排量、变速箱、排放标准等）。
- 第四屏：车况/检测报告入口卡片。
- 底部固定操作栏：左侧「收藏」「分享」图标，右侧 primary 色大按钮「电话联系」。

## 五、可访问性

- 主要文字与背景对比度 ≥ 4.5:1。
- 所有可点击区域 ≥ 44×44px。
- 图片提供 alt / 加载占位。
- 价格、关键操作使用颜色 + 字号双重强调，不依赖颜色唯一表达。
