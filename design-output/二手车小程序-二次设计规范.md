# 二手车买卖小程序 · 设计规范 v2（终版）

> 本规范与 `prototype.html` 高保真原型、`pages/*` 小程序实现三者保持一致。
> 设计基调：**明黄主色 + 白底卡片 + 红色价签 + 圆角轻量化**。

## 一、设计目标

1. 保留「明黄 + 白卡 + 红价签」品牌记忆点，去掉上一版的廉价感（emoji 图标、橙色急卖角标、满屏黄价格条）。
2. 全量使用 **SVG 图标**（data-URI / inline symbol），不再使用任何 emoji。
3. 首页 / 搜索结果 / 批发车 共用同一套车源卡片，体验一致。
4. 自定义 TabBar，图标灰 / 黄双态，替代原生占位。

## 二、色彩（Design Tokens）

| Token | 值 | 用途 |
|-------|----|------|
| `--primary` | `#FFB800` | 主按钮、定位标、Tab 激活态、急卖角标、渐变头图 |
| `--primary-dark` | `#F0A800` | 主色按下态、价格/文字强调 |
| `--primary-light` | `#FFF6DD` | 选中/标签底色、关键参数卡底 |
| `--price` | `#E53935` | 价格、强提示（红价签） |
| `--text-1/2/3` | `#1A1A1A / #666 / #9AA0A6` | 主/副/辅助文字 |
| `--bg` | `#F4F5F7` | 页面背景 |
| `--card` | `#FFFFFF` | 卡片背景 |
| `--border` | `#EEF0F2` | 分割线 |
| `--green` | `#2BA471` | 优势标签（一手车/无事故）、车况通过 |
| `--orange` | `#FF7A29` | 急卖角标、热门排名 |

## 三、字体 / 圆角 / 阴影

- 字体栈：`PingFang SC, -apple-system, ...`
- 价格 18–20px / 700 / 红色；标题 28–32rpx / 600；正文 26rpx；辅助 20–22rpx。
- 圆角：`--r-sm 8rpx` / `--r-md 16rpx` / `--r-lg 24rpx` / `--r-pill 999rpx`。
- 阴影：`--shadow-card 0 4rpx 16rpx rgba(0,0,0,.04)`（卡片）；`--shadow-float`（悬浮发布/主按钮）。

## 四、核心组件

### 4.1 车源卡片（首页 / 结果 / 批发车共用）
- 左图 240×180rpx，圆角 8rpx；左上「急卖」橙角标，右上「新上架」半透明角标。
- 右侧：标题（单行截断）→ 年份·里程·城市（辅助色）→ 标签（燃料蓝 / 优势绿 / 普通灰）→ 价格行（红价签大号 + 新车指导划线价）。
- 卡片白底、16rpx 圆角、微阴影，按下态 `#fafafa`。

### 4.2 搜索卡（首页顶部）
- 白底胶囊：`定位(主色图标)+城市+▼ | 输入 | 搜索(主色按钮)`，搜索框聚焦态不变黄背景，仅在按钮与定位图标用主色。

### 4.3 筛选栏
- 四个等分项，选中态 `主色文字 + 底部 2rpx 主色指示线`。

### 4.4 详情页
- 顶部全宽画廊（带计数 + 保存图片）；价格卡上抬 28rpx 覆盖画廊底边；关键参数三列（主色浅底）；车辆档案两列参数表；车况评分卡（绿勾）；卖家卡；底部固定栏（收藏/分享/电话联系）。

### 4.5 自定义 TabBar
- 高度 100rpx + safe-area；白底、顶部 0.5px 阴影；图标 44rpx，未选中 `#9AA0A6`、选中 `#FFB800`，文字同步。
