# TabBar 图标说明

项目需要准备以下图标文件，放在 `assets/icons/` 目录下：

## 图标列表

| 文件名 | 用途 | 尺寸建议 |
|--------|------|----------|
| home.png | 首页-未选中 | 81×81 px |
| home-active.png | 首页-选中（黄色） | 81×81 px |
| wholesale.png | 批发车-未选中 | 81×81 px |
| wholesale-active.png | 批发车-选中（黄色） | 81×81 px |
| service.png | 服务-未选中 | 81×81 px |
| service-active.png | 服务-选中（黄色） | 81×81 px |
| mine.png | 我的-未选中 | 81×81 px |
| mine-active.png | 我的-选中（黄色） | 81×81 px |

## 车辆图片占位

需要在 `assets/images/` 目录下放置测试车辆图片：

- car1.jpg ~ car6.jpg（首页列表）
- detail1.jpg ~ detail7.jpg（详情页轮播）

## 临时方案

开发阶段可使用在线占位图服务：
- 首页车辆图片：`https://picsum.photos/400/300?random=1`
- 详情页轮播：`https://picsum.photos/800/600?random=1`
